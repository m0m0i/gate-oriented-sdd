### Decisions

- **0.6.0, and the major stays unspent — but not for the reason first given.** AC13 was drafted at
  `1.0.0` on the recorded reservation of the major for the minimum/full switch, with the counter-case
  argued from `.steering/product.md`'s "not a supported product". **That argument was wrong and is
  withdrawn.** This is an open-source repository, so nobody or everybody supports it, and that line
  disclaims *support* — an SLA, a maintainer on call — which is true at every version and says
  nothing about compatibility, which is what a major actually signals. Two senses of one word,
  collapsed. The real counter-case is **#82**: it must relocate the reviewer contract to one settled
  path, three documents currently place it three ways, and landing that after `1.0.0` breaks every
  consumer pinned to the old location — a `2.0.0` by semver. This plugin has downstream consumers
  that pin copied modules per version, so that is migration work someone actually performs rather
  than a hypothetical. So the reservation is honoured rather than overridden: **the trigger has
  arrived, the interface is not yet safe to freeze, and `1.0.0` follows #82.**
- **The checker is a guard the project owns, never a hook.** `quality-gate.sh` runs whatever
  `- Validators:` names and knows nothing about modes. A gate that branched on mode would be a
  switch that turns enforcement down, which is AC5 — and declining to close the turn-end gap is that
  criterion working, not a hole left open.
- **CI is where this one actually bites, and that was a HIGH.** The `- Validators:` line runs only
  when a path matching `- Source globs:` changed, and a document is never source: the two sets are
  **disjoint by construction**, because one line points at documents and the other at code. So the
  checker ran on exactly the turns where nothing it checks could have changed. Demonstrated before
  fixing — `rm docs/CONTRACT.md`, checker exits 1, turn-end gate exits 0. Fixed with a CI step and
  the sentence `init` already carried for `check-locks.py`.
- **`contract` stays out of `minimum` and runnable at any time**, because its own step 1 asks for the
  last fifty commits and its red flags name copying a style guide wholesale — run early it produces a
  *worse* rulebook rather than an absent one. And `spec`'s side-door accusation is scoped to `full`,
  since in a project that never batches `sprint` it fires on every spec and trains the user to skip
  the rule that matters.
- **Accepted rather than fixed:** round 4's LOW — `cf1`/`cf2` are absent from the case's detail
  string, so a red run does not say which half broke. `scripts/` is inside `Source globs`, so fixing
  it would re-stale a CLEAN receipt and buy a fifth round for one line of diagnostics. The remedy is
  written down for whoever next touches that file.
- **One receipt field deviates from verbatim, and it is recorded rather than quiet.** The reviewer
  wrote `high=1` and flagged the ambiguity itself: rounds 1-3 each carried a HIGH against an earlier
  SHA, and none remains at `ae1d607`. Written `high=0`, because the field describes the reviewed SHA
  and #109's own final receipt is the precedent.

### Three lessons, all earned the expensive way

- **A fix is not finished when it is correct; it is finished when reverting it turns something red.**
  Round 2's parity fix shipped unpinned, and restoring the defect left all 71 cases green.
- **A safety check is not a safety check until something fails when you break it.** Fixing one
  silent-green fixture took three attempts: `assert` (rejected by this suite's own guard — `python -O`
  strips them, #28), then a bare `raise` (the shell does not inspect a heredoc python's exit status,
  so it died into stderr and the case passed anyway), then binding the status into the report.
- **Mutate the fixture, not only the subject.** The second failure above was found by breaking
  `docset_repo`'s format string and watching the case stay green. Every mutation test here until now
  has broken the thing under test; this one broke the thing doing the testing, and nothing in the
  rulebook tells anyone to try it.
