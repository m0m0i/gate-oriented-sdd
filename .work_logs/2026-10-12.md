### Decisions

- **Mechanical friction on downstream documents**: Deliberately requiring manual verification and re-stamping when `PRD.md` is updated. This prevents unnoticed downstream drift across architecture, roadmap, and backlog plans.
- **Fail-closed git history checks**: If `PRD.md` has uncommitted modifications, or git history is unresolvable (e.g. detached/unborn HEAD), the checker fails closed with an actionable message rather than assuming validity.
- **Bootstrap mode deferral**: In `bootstrap` mode, inception documents are not yet authored, so the cascade check defers with exit 0 and an informative diagnostic message, matching `assets/check-document-set.py`.
- **Standalone validator on `- Validators:`**: Built as a standalone Python 3 script (`assets/check-document-cascade.py`) copied into consumer projects by `init` and run on every turn end and CI build.
