### Decisions

- **`implement` mandates a synchronous reviewer invocation, and says how to wait (#27).** The first version of that spec rested on "an agent has no wait primitive". **That is false** — a turn ends on a final message with no tool call, so it stays open across tool calls. The twenty-five-turn deadlock was caused by saying *"Holding."* between checks, each of which ended the turn and re-armed the gate. Rules out any gate-side fix: nothing the gate can do breaks the loop without letting it pass, which is a fail-open on the only enforced rule. Verified by demonstration and recorded in `docs/verified.md` with that provenance.

- **`docs/verified.md` row 3 was written as observed before it had been done.** Caught in review. The file whose entire purpose is separating observed from asserted had blurred them in the row an entire branch rested on. Provenance is now split per row and the confession kept. **This is the single most useful finding of the day** and the reason to keep the reviewer independent.

- **One PR per issue (#30).** `spec`'s lifecycle table said `approved` meant "the spec PR merged"; its rules said one issue = one branch = one PR. The rules won. What it gives up is written into the skill rather than glossed: a merge used to sit between agreeing and building, and now nothing mechanical does. Rules out the two-PR flow and halves the merges.

- **`strict_required_status_checks_policy` turned OFF.** With several PRs open, each merge made every other one `BEHIND`, so a chained merge could only ever land the first. Costs: a PR can now merge green against a `main` it was never tested against.

- **The dogfood reviewer's rulebook stays unpinned**, and `#16`'s fix did not change that — pinning still needs #19.

- **Accepted rather than fixed, all recorded in #39**: six guards can report success having checked nothing, and `report` has no `skip` state, so `45 passed` can mean 44 verified plus one skipped. Includes **a regression #34 introduced and did not fix** — routing the quality gate's read through the shared function suppressed the `Permission denied` on stderr, removing the only signal that an unreadable `tech.md` was being read as an absent one.

- **#26 was used four times as an escape**, disclosed each time. `git checkout main` silences the review gate completely. It is the top of the backlog and has been through two branches.

### What went wrong on our side, recorded because the pattern is the point

- **Three `.replace()` calls silently no-opped and were reported as fixed.** Every one was an edit not wrapped in `assert t.count(old) == 1`. Where the assert was present, a bad needle failed loudly and nothing was written.
- **Two tests were shipped that could not fail** — an untested `|| comm -23 <(...)` fallback using non-POSIX process substitution, and an assertion left guarding a string a later rename had removed.
- **A retracted premise leaves three kinds of residue**: the sentence, the conclusions drawn from it, and the choices made because of those conclusions. The third lives in files that never mention the premise. It took three review rounds, one per layer.
- **Recording a suspected defect instead of acting on it saved a guard.** The stale-lib ordering in `quality-gate.sh` looked like a fail-open traded for a false block; two reviews traced the paths and showed the only reachable state is a broken manual install.

### Decisions
- **`assert` is banned in `scripts/`, `assets/`, `hooks/`, and the ban is pinned by case 35** — not left as convention. `assert` is the one Python statement the interpreter may delete, so a safety check written as one is a check `PYTHONOPTIMIZE=1` removes. Rules out relying on review to catch the next one; the convention had already been deviated from once in eleven consistent sites.
- **Kept the `continue`-on-missing-mirror rather than deleting it.** Deleting the unreachable branch removes the invariant that has to protect it, but also the comment explaining why the skip is safe — and that comment is the part the issue singles out. Rules out the belt-and-braces variant, which would have left the surviving comment describing a skip that no longer exists.
- **`docs/BACKLOG.md`:38 deliberately left at `45 passed` / 44 verified** while five other count sites moved to 47. It illustrates #39's argument and the pairing is what carries it; renumbering would preserve a number and lose the point. Recorded so it reads as a choice, not a miss.
- **Accepted rather than fixed, both reviewer INFOs, both argued by the reviewer as belonging to #39**: case 35's `scripts assets hooks` list is a guard's own list in G-8's sense and can fall behind a fourth guard directory with no source of truth to derive from; and its `rc -eq 2` branch is unexercised, because case 35 scans `$ROOT` itself, so driving that branch would mean making part of the live repo unreadable mid-run. Testing it properly needs the case to take its work-set as a parameter — #39-shaped, not #28-shaped.
