### Decisions

- **A shipped script, not prose (C1).** The comparison and the JSON merge are deterministic work, and `sed` corrupts a fast check holding `&`.
- **A table of every first-parent text, with no stamp and no current-only comparison (C2).** A stamp helps only future installs. A current-only comparison makes every stale copy a question. Tags miss shipped states.
- **Every render since v0.2.3 is upgraded (C3).** v0.2.0's inlined command is AC6's question.
- **A batch report, and a fresh install through the same script (C5, AC8, AC10).** An automatic notice at session start is out of scope until row 2's probe measures the plugin path on a current CLI.
- **Refuse what Antigravity's handling is not recorded for, rather than guess.** That covers a hook whose type is not `command`, an empty `hooks` list and a missing matcher. It fails closed.
- **Stopping at round 6's CLEAN.** Six rounds is the bound. Fixing below-HIGH after a CLEAN would only re-stale the receipt.
- **Recorded, not fixed, after CLEAN.** Every item fails closed:
  - MEDIUM: a gate `timeout` written `600.0` reads as current, because Python's `600 == 600.0`, while the gates read no integer timeout and block every turn. The fix is to compare by type, for example by `dump()`.
  - MEDIUM: a project `Stop` entry between the two gates moves after them, so an otherwise current file reads as behind.
  - MEDIUM: some refusals say "Antigravity rejects the whole file" for shapes `docs/verified.md` does not record, and "1e400 … is not JSON" is inaccurate under RFC 8259. The message should say "refused rather than guessed at".
  - LOW: the "--fast-check-enabled false" note is printed for every deleted entry, not only the fast check.
  - LOW: a deeply nested file raises `RecursionError` and ends a batch early.
  - INFO: NaN and Infinity are refused, where AC6's "not JSON" path would propose. That is a stricter reading than the spec states.
- **T6's findings outside #343, carried as follow-ups:**
  - **A vendored plugin copy.** One under `.agents/plugins/gate-sdd/` makes a session read an older `init` first, and nothing `init` ships reaches it.
  - **An upgraded install can start blocking at once.** On an install older than a check, the re-run's new harness checks fail it from the first turn (the consumer's ROADMAP and cascade stamps).
  - **The agent's summary left out failures.** Both runs omitted the refused first write, and R4 also omitted the failing checks. `init` now says to run the harness checks and report.
