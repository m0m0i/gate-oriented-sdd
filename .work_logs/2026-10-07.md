### Decisions

- **Evidence that a copy runs is the entry and the file, together.** The file alone was never evidence (row 1's finding); the entry alone turned out not to be either (round 2). A path through a variable does not resolve and runs the plugin's gate, the noisy direction, on purpose.
- **A wrapper, not guarded JSON one-liners.** A guard in a JSON string is one nobody tests; `test-gates.sh` runs the wrapper against the real gates.
- **`$CLAUDE_PLUGIN_ROOT/hooks` is read last by the checks**, so a dogfood turn in this repository reads `hooks/` from source, never an installed copy. This repository's own settings entries are what stand the installed plugin's gates down here, confirmed by running the wrapper.
