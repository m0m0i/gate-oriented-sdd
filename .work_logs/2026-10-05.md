### Decisions

- **No plugin agents at all, where the issue asked only about the rulebooks.** The three reviewers name a contract and rules that exist only after `init`. Keeping them registered keeps an agent with no contract before `init` and a duplicate of the project's pinned reviewer after it. ADR-7.
- **`reviewers/` at the top level, not `assets/reviewers/`.** It has the shape of the directory `init` writes, and it puts the judgment layer beside `skills/` and `hooks/`. The cost is one more shipped path in the packager, `SHIPPED` and `- Source globs:`.
- **No manifest `agents` key.** With no `agents/` directory there is nothing for it to list, and with the key set `claude plugin details` reports no agents at all, which is its own wrong reading.
- **`.claude/CLAUDE.md`, not deleting `CLAUDE.md`.** #237 chose the import over deletion; this keeps that choice and moves the file out of the plugin root.
- **The frontmatter check went into `check-manifests.py`**, not a new script. A new script is a new entry on the `- Validators:` line, in `AGENTS.md`, in CI and in the reviewer's allow-list, for forty lines.
- **`check-locks.py` replaces `agents` in its candidates.** Keeping it would have the shipped checker scan a directory this repository's own guard forbids. The reviewer's LOW is the other side of that, and is recorded.
- **Minor, not patch:** shipped paths move and `init`'s source changes. Not a major: the installed tree does not change, and the interface a major would freeze is still row 9's.
- **Stopped at CLEAN.** Document findings were fixed, since no document is on `- Source globs:`. The two that want source were recorded.
- **#249 is one issue, under `## Open, not planned`.** Placing it is a refinement's call.
