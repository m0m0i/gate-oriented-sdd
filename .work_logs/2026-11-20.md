### Decisions

- **Fixture homes take the skip and do not register the hook** (spec amendment `e4bfa50`). The probe costs about 0.3 s per guard run, and the suite has about a hundred guard runs, which would have pushed it past its budget. Only the check's own cases register it.
- **The reference is the default branch's copy**, so a branch never has to install its work in progress for every session. Until #361 merges, the default branch has none, so this branch's copy was the reference, and each review fix was installed on the maintainer's go.
- **A matcher Claude Code would read as a regular expression is refused, not interpreted.** A false refusal costs one edit back to the printed matcher. Modelling JavaScript regular expressions could fail open.
- **A switch counts as on unless it is JSON `false` or `null`.** The managed-settings documentation reads an invalid lock as locked, so the check errs the same way.
- **The suite budget is 480, not twice the line.** Twice the line, as e0b4fcf set it, would be about 670, past the quality gate's 590 s ceiling (its 600 s `Stop` timeout less 10 s). 480 is about 1.4 times the worst run, 333 s.
- **Accepted from the reviews, not fixed**, to keep the CLEAN receipt fresh. Each is below HIGH and fails closed or is a matter of record:
  - MEDIUM: `docs/verified.md`'s #361 section has no per-AC outcome table. The runs are recorded, but not mapped to AC1 to AC11.
  - LOW: the probe accepts any exit 2 as blocking its synthetic write. An install whose guard faults on every write would pass the probe, but it also blocks every write.
  - LOW: a reference with no `GH_GUARD_VERSION` line skips the version and byte comparison in silence. The probe still runs, and the installer refuses such a source.
  - LOW: ADR-13 says 43 ms in its Alternatives and 42 ms in its Consequences.
  - LOW: a failed `mkdir` of the reference directory is reported as an unreadable file. It still fails closed, and `$TIERS` has already been checked to be a directory.
- **Left open from the registration hunt.** Contrived, and so an adversarial agent's, out of scope: a newer installed copy that detects the probe; modules or a compiled file planted beside the install; a `python3` on `PATH` that exits 0 in silence. Not matched: a settings file that is valid JSON but fails Claude Code's schema, and `CLAUDE_CODE_SUBPROCESS_ENV_SCRUB` hiding `CLAUDE_CONFIG_DIR`. One claim was refuted by the spec's own measurement: a settings `env` block moving the pattern file.
- **Not cased:** the shell's own early skip, which duplicates the module's skip so that a machine without Claude Code needs no python3.
- **Worth noting for future sessions.** The registered hook blocks a here-document holding a `gh` word that is fed to `python3`, which is how this session staged its own commits. Write such a script with the Write tool and run it by its path.
