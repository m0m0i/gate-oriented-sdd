### Decisions

- **Option 3 (CI Release Distribution Artifact `gate-sdd.zip`):** Preserves the foundational architecture ("the repo root IS the plugin", dual-manifest layout, no nested directories) while providing consumers who want payload isolation a clean artifact without repo-internal dev tooling.
- **Rejected Option 1 (`.gitattributes export-ignore`):** Marketplace installations clone the git repository directly, so gitattributes export-ignore rules never apply to the common install path.
- **Rejected Option 2 (`plugins/gate-sdd/` subfolder):** Moving the plugin into a subfolder violates `docs/layout.md`, fractures the dual-manifest layout, and breaks downstream pinned references and git clone installation without templating.
- **Support target directory in `scripts/check-manifests.py`:** Enforces **gates never fail open** during release packaging verification by evaluating the unpacked payload rather than the repository root.
- **Minor version bump (0.14.0):** Introducing standalone release artifact packaging and automated tag-triggered release distribution is a new plugin delivery capability.
