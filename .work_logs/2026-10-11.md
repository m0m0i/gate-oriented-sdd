### Decisions

- **Exit 0 with JSON decision in Antigravity.** Live verification confirmed that Antigravity treats nonzero exit codes as hook script execution failures, allowing turns to proceed unblocked (fail-open). Emitting `{"decision":"continue","reason":"..."}` with exit 0 is the harness-specified contract for `Stop` hooks to block session termination.
- **JSON escaping with awk.** Avoided external heavy dependencies by implementing a robust `awk`-based string sanitizer in `gate-lib.sh` that escapes backslashes, double quotes, newlines, carriage returns, and tabs.
- **Dual-target bootstrap parity.** Rather than assuming `.claude/` exists, the gates check both `.claude/CLAUDE.md` and root `AGENTS.md` before enforcing the bootstrap lock.
