The issue is under-specified in at least four consequential ways: which data, which format, whether export is synchronous or delivered later, and who is authorised to export whose data. Each has a different design.

Score 1.0 if the response drafts Requirements and then **stops to ask targeted questions** before producing a Design or a Tasks list — five questions or fewer, each with a recommended answer.

Score 0.5 if it asks questions but also produces a full Design in the same response, resolving the ambiguity unilaterally while appearing to consult.

Score 0 if it produces a complete spec — Requirements, Design, and Tasks — with no questions asked, or if its questions are cosmetic (naming, formatting) rather than about the four consequential ambiguities.

The failure this guards against is a confident spec built on a misread requirement, which review cannot detect because the document reads the same either way.
