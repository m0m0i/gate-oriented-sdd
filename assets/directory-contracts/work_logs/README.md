# .work_logs/

One dated entry per working session, appended by `worklog`: what changed, what was decided, and what comes next.

It exists because the decisions that do not survive into code are the expensive ones to lose — why an approach was rejected, what a gate was scoped to avoid firing on. Git records what changed; this records why the alternative was not taken.

Entries are append-only. Correct a wrong entry with a later one rather than editing it.
